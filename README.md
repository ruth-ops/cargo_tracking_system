# Cargo Tracking System
**The problem:** Local logistics companies waste time and resources on manual phone calls to track shipments, so this system provides an automated digital pipeline to record parcels, generate tracking numbers, and look up real-time statuses instantly.
#### This project helps a cargo company record shipments and updates where each one is so that stuffs and customers can check a parcel's status with a tracking number instead of phoning around 
####By **Ruth**
##Description
This application is a local cargo and parcel tracking management system designed for logistic companies.It allows staff members to register incoming shipments,generate unique tracking numbers,update cargo location statuses as packages move through the delivery pipeline and allow customers or operators to query package progress without manual follow-up phone calls,the system stores shipments records persistently in a relational database
